# Ruta Mundo - Agencia de Viajes

Es una página web responsiva para una agencia de viajes que permite explorar destinos y simular una reserva.

## Tecnologías utilizadas
* HTML5: Estructura del sitio.
* CSS: Estilos personalizados (degradados, sombras y tipografía).
* Bootstrap: Diseño responsivo, navbar, tarjetas y formularios.
* JavaScript Lógica para capturar datos, validar el formulario y calcular el valor de la reserva simulada.

## Funcionalidades
* Catálogo con 8 destinos turísticos.
* Formulario de reserva simulada con validación (no permite nombres vacíos ni cantidades erróneas).
* Cálculo automático del precio total según el destino y la cantidad de personas.
* Diseño adaptado para celulares y computadores.

## Cómo usar el proyecto
1. Clona este repositorio o descarga los archivos.
2. Abre el archivo `index.html` en cualquier navegador web.
3. Navega por el catálogo y prueba el formulario de reserva en la parte inferior.
